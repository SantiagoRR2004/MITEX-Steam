# Interactive assistant specialized in Steam video games

## Overview

This is a project for a subject called "Minería de Textos" (Text Mining) that accounted for 20% of the final grade. It was made by a team of 3 people. The submission took place on Friday, the 12th of June of 2026, and earned a grade of 10 out of 10 points.

## Project Summary

For this project, we had to design and implement a complete solution for an interactive assistant specialized in a specific knowledge domain. We chose the domain of Steam video games, and we implemented a chatbot that can answer questions about video games available on the Steam platform. For this, we scraped the top-selling video games for each day and stored the information in a database that served as the knowledge base for the RAG system. The chatbot architecture is comprised of multiple nodes that are responsible for different tasks. The LLM chooses the appropriate node based on the user query.
